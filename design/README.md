# 휘연당 디자인 자료

사이트 개발에 필요한 기획 문서, 화면 시안, 캐릭터 이미지, 디자인 토큰을 모아둔 폴더입니다. 만세력 계산은 [`../saju-engine`](../saju-engine)에 있습니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `docs/01-plan.html` | 서비스 기획서 (컨셉, 사용자 흐름, 상품·가격, 계산 기준, 법·윤리 체크) |
| `docs/02-characters.html` | 캐릭터 설정서 (서휘·하연 프로필, 관계, 친밀도 단계, 운영 규칙) |
| `docs/03-tone-guide.html` | 풀이 톤 가이드 (3단 구조, 문체, 금지어, 민감 주제, 언어 모델 시스템 프롬프트 초안) |
| `screens/` | 화면 시안 PNG (2배 해상도). `00-overview.png`는 전체 흐름 한 장 |
| `wireframes/` | 화면 시안 원본 (`*.dc.html`, `canvas.json`). 동작 규칙과 문구를 확인하는 참고용 |
| `assets/characters/hwi-poses/` | 서휘 포즈 24종 (보름달 스티커, 234px webp) |
| `assets/characters/yeon/` | 하연 보름달 스티커, 얼굴 스티커 |
| `assets/characters/*.webp` | 서휘·하연 전신 (배경 투명), 두 사람 함께 |
| `assets/source/` | 받은 원본 이미지 (캐릭터 2인 원본, 서휘 포즈 시트) |
| `tokens.css` | 색, 글꼴, 모양 토큰 |

`docs/*.html`은 브라우저로 바로 열립니다. `wireframes/*.dc.html`은 디자인 캔버스 전용 형식이라 브라우저에서 그대로 렌더되지 않습니다. 화면 모습은 `screens/` PNG를, 문구와 동작은 `.dc.html` 안의 마크업과 스크립트를 보면 됩니다.

## 동작 규칙 (개발 시 지킬 것)

- **풀이 내용:** 간지·십신·충은 `saju-engine` 계산값만 씁니다. 언어 모델이 직접 계산하지 않습니다.
- **산통 흔들기:** 결과는 오늘 일진과 손님 일간의 십신 관계로 정합니다. 랜덤이 아니고, 같은 날 다시 흔들어도 같은 결과입니다. 흔드는 동작은 연출이라는 사실을 화면에 표시합니다.
- **스티커:** 출석, 풀이, 궁합, 공유 같은 활동으로만 엽니다. 결제로만 열리는 스티커는 두지 않습니다.
- **결제:**
  - 플랜을 미리 선택해두지 않고, 결제 버튼 바로 위에 자동결제 조건을 표시합니다.
  - 거절 버튼은 결제 버튼과 같은 크기로 둡니다.
- **해지:**
  - 2단계로 끝냅니다.
  - 해지 사유 설문은 선택이고, 답하지 않아도 해지됩니다.
  - 우는 포즈 같은 죄책감 유도 연출은 쓰지 않습니다.
- **개인정보 동의:** 동의 체크박스는 미리 체크해두지 않습니다.
- **AI 생성물 표시:** 풀이 문장과 캐릭터 이미지가 AI 생성물이면 그 사실을 표시합니다.

법령 관련 세부 기준(전자상거래법 다크패턴 규정, AI 기본법 표시 방식)은 `docs/01-plan.html`의 법·윤리 체크를 보고, 출시 전에 원문으로 확인합니다.

## 예시 값

화면 속 오행 수치, 운세 지수, 출석 일수, 스티커 7/24, 가격은 시안용 예시입니다. 일간 갑목 예시 풀이의 간지 관계(갑목에게 병화는 식신, 2026 병오년, 2027 정미년, 축미충)는 명리 규칙에 맞춰 썼습니다.
